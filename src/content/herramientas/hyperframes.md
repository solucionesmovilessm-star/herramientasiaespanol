HyperFrames es un framework de HeyGen para convertir HTML, CSS, media y animaciones en vídeos MP4 de forma determinista: la misma entrada produce el mismo vídeo. Se puede usar en local con la línea de comandos, desde un agente de programación o como motor de renderizado.

## Qué puedes hacer

- Montar un vídeo a partir de HTML y CSS, en tu máquina.
- Pedírselo a un agente de programación (Claude Code, Codex, Cursor y otros). Las skills se instalan con uno de estos comandos:

```bash
npx hyperframes skills update
npx skills add heygen-com/hyperframes
```

- Usar el estudio web, que también tiene un plan gratuito.

## Precio

El código es gratis y de código abierto, con licencia Apache-2.0. El estudio, según su [página de precios](https://hyperframes.studio/pricing), tiene estas tarifas en dólares:

- **Free:** 0 $. Incluye 3 clips de vídeo con IA al mes y 5 exportaciones en la nube al mes, con 5.000 créditos iniciales.
- **Pro:** 25 $ al mes, con 25.000 créditos. Incluye los modelos de vídeo, imagen, voz y música de HeyGen y de terceros.

HyperFrames Pro es independiente de los planes de HeyGen, según esa misma página. El código está en [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) y la web del proyecto es [hyperframes.heygen.com](https://hyperframes.heygen.com).
