Anthropic publica Claude en [claude.ai](https://claude.ai). Va bien cuando el texto es largo: un contrato, unos apuntes o un informe que quieres rehacer con un tono concreto.

## Qué puedes hacer

- Pegar un documento y pedir un resumen, una tabla o una lista de dudas.
- Crear archivos en el chat cuando tu plan tiene esa función activa.
- Usar skills ya preparadas o subir las tuyas. El paso a paso está en el tutorial [cómo añadir skills a Claude](/tutoriales/como-anadir-skills-a-claude).

## Precio

Se puede usar sin pagar, con límites. Los planes de pago cambian lo que incluye el chat, incluidas las skills personalizadas. Comprueba el plan en la web de Anthropic.

## Ten en cuenta

Una skill puede pedir a Claude que ejecute instrucciones y código. Usa solo las que hayas leído o las que publique Anthropic. Más fichas en [Skills para Claude](/skills/claude).
