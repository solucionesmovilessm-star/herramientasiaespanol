Microsoft Copilot es el asistente de Microsoft. La versión web está en copilot.microsoft.com. En Windows y en las aplicaciones de Microsoft 365 aparecen funciones con el mismo nombre, y no todas hacen lo mismo.

## Qué puedes hacer

- Preguntar y redactar desde el navegador, sin instalar nada.
- Pedir ayuda dentro de Word, Excel o el correo si tu suscripción de Microsoft 365 lo incluye.
- Usar la versión de Windows si ya viene en tu equipo.

## Precio

La web se puede probar gratis, con límites. Las funciones dentro de Microsoft 365 dependen del plan. Mira la página oficial antes de asumir que tu suscripción ya las trae.

## Ten en cuenta

“Copilot” también es el nombre del asistente de programación de GitHub. Si buscas ayuda para código, la ficha es [GitHub Copilot](/herramientas/github-copilot).
