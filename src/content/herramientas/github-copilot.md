GitHub Copilot es el asistente de programación de GitHub. Sugiere código en el editor y también se usa en la web de GitHub. No es el mismo producto que Microsoft Copilot, aunque compartan la palabra.

## Qué puedes hacer

- Pedir una función y revisar la sugerencia antes de aceptarla.
- Preguntar por un error en el archivo que tienes abierto.
- Usarlo en editores compatibles, entre ellos VS Code.

## Precio

Hay un plan gratuito con límites y planes de pago. Qué incluye cada uno está en la página de GitHub. Esta ficha no copia precios.

## Ten en cuenta

El código sugerido puede estar mal, ser inseguro o parecerse a otro código. Léelo y pruébalo. Si el proyecto no es tuyo, respeta su licencia.
