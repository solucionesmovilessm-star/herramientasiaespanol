Runway es una herramienta de vídeo con IA. La dirección runwayml.com redirige a runway.com, que es la web actual. Sirve para generar un clip a partir de un texto o de una imagen y para retocar vídeo.

## Qué puedes hacer

- Generar un clip corto a partir de una descripción.
- Animar una imagen fija.
- Probar herramientas de edición que la cuenta deje usar.

## Precio

Hay créditos gratuitos y planes de pago. El vídeo consume el cupo deprisa. Las cantidades están en la web de Runway y no se copian aquí.

## Ten en cuenta

Un clip generado puede tener movimientos raros en manos, texto o física. Míralo entero antes de publicarlo.
