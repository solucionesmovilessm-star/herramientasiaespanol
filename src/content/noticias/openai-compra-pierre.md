## Qué ha pasado

OpenAI anunció el 4 de noviembre que **adquirirá Pierre Computer Company, Inc.** («Pierre»), la empresa detrás de **Code Storage** y de varias herramientas open source para desarrolladores.

Si has revisado cambios o navegado por archivos en la **app de Codex**, ya has usado su trabajo: Codex usa sus librerías **Trees** (navegar por los archivos de un proyecto) y **Diffs** (ver qué ha cambiado). Pierre también ha lanzado hace poco **Highlights**, un resaltador de sintaxis muy rápido que se actualiza mientras escribes o mientras un agente genera código, y Diffs tiene un modo de edición para corregir una línea justo donde ves el problema.

**Code Storage** es un servicio con API que permite a las apps guardar código y seguir su historial usando Git.

OpenAI no ha publicado el importe de la operación.

## Por qué importa

OpenAI quiere que **Codex sea el sitio donde desarrolladores y agentes hacen sus proyectos**, desde la primera rama que crea un agente hasta el despliegue. Pocos días antes contó cómo escala Git internamente con **Pando**, su propio backend de control de versiones para ingenieros y agentes. Con Pierre, dice, quiere «marcar el estándar» del desarrollo de software y «hacer avanzar el futuro del control de versiones».

Leído en clave de mercado: OpenAI se mete en el terreno del alojamiento y la revisión de código, el de GitHub y otras plataformas de control de versiones como Cursor Origin. (Esto es interpretación nuestra; OpenAI no menciona competidores.)

## Qué cambia para ti

- **Open source:** Trees, Diffs, Highlights y el resto de proyectos de Pierre **seguirán siendo open source** y OpenAI seguirá contribuyendo.
- **Clientes de Code Storage:** podrán seguir usándolo tras el cierre mientras OpenAI lleva sus funciones a Codex.
- **Aún no está cerrada:** la compra depende de las condiciones habituales, incluidas **aprobaciones regulatorias**. Hasta entonces, OpenAI y Pierre siguen siendo empresas independientes.
