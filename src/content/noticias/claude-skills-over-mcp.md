Coincidiendo con el segundo aniversario del Model Context Protocol, Anthropic abrió la beta pública de Skills over MCP en Claude y Claude Code: los servidores MCP pueden publicar habilidades (flujos de trabajo y buenas prácticas) junto a sus herramientas, y Claude las carga solo cuando las necesita. Tasks (tareas largas en segundo plano) y Elicitation (pedir confirmación o datos al usuario a mitad de una operación) pasan a estar disponibles de forma general en planes Pro, Max y Ultra, y se están desplegando en Team y Enterprise. Anthropic afirma que los SDK de MCP superan los 700 millones de descargas mensuales y que File Uploads llegará pronto; no está ya disponible para todo el mundo.
