El OpenAI Agents SDK es la librería de OpenAI para construir agentes en código: herramientas, traspasos entre agentes y un bucle que decide el siguiente paso. El repositorio de Python es el enlace de esta ficha.

## Qué puedes hacer

- Definir un agente con herramientas que tú escribes.
- Encadenar más de un agente cuando la tarea se parte en papeles.
- Ejecutarlo contra la API de OpenAI desde un programa propio.

## Precio

Descargar el SDK no tiene un precio aparte. Cada llamada a un modelo se cobra en la cuenta de OpenAI según la tarifa de ese modelo. Por eso la ficha dice “gratis con límites”: el programa es abierto y el uso no es gratis.

## Ten en cuenta

No subas la clave de la API a un repositorio. Léela desde una variable de entorno y revisa el diff antes de publicar el código.
