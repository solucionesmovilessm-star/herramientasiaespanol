OpenBot de CopilotKit es una plantilla para montar «compañeros de trabajo» de IA dentro de la infraestructura de tu empresa. No es la app de escritorio [OpenBot de nightly-labs](/agentes/openbot): otro autor, otro repositorio y otro uso. Tampoco es [OpenMausBot](/agentes/openmausbot).

Cada agente tiene su propio navegador, sus archivos y sus herramientas. Lo que hace pasa por una pasarela: un control que decide si esa acción se permite y la deja registrada.

## Qué puedes hacer

- Alojarte tú el sistema. Está en beta y no hay una versión ya alojada por CopilotKit: se clona el repositorio y se adapta.
- Usar agentes compatibles con el protocolo AG-UI, entre ellos LangGraph, Mastra, CrewAI y Google ADK. AG-UI es un idioma común para que la interfaz hable con el agente.

## Precio

El código es gratuito y abierto, con licencia MIT. Hace falta un proyecto de CopilotKit Intelligence, que tiene un plan gratuito, y una clave de un modelo de IA. Esa clave puede tener coste.

## Ten en cuenta

A 30 de octubre de 2026, hacia las 08:00 (hora de Madrid), el repositorio tenía unas 8.300 estrellas según la API de GitHub. Ese mismo día, el listado diario de GitHub le marcaba unas 247 estrellas más. La web del proyecto es [copilotkit.ai/openbot](https://www.copilotkit.ai/openbot).
