AutoGen es un marco de Microsoft para programar conversaciones entre varios agentes. El código está en el repositorio oficial. Microsoft ha ido reuniendo piezas de agentes en otros proyectos: antes de seguir un tutorial viejo, lee el README actual por si el nombre o el paquete han cambiado.

## Qué puedes hacer

- Definir agentes que se hablan para resolver una tarea de código.
- Usar la librería en un proyecto propio.
- Leer los ejemplos del repositorio antes de escribir el tuyo.

## Precio

El código del repositorio es abierto. Las llamadas a un modelo de pago se cobran en la cuenta de ese modelo. “Gratis” aquí se refiere al marco, no a la factura del modelo.

## Ten en cuenta

Un ejemplo del repositorio puede estar desactualizado. Si un comando del README falla, mira la fecha del último cambio y las issues abiertas. Cómo leer un repo está en el tutorial [cómo usar un repositorio de GitHub](/tutoriales/como-usar-un-repositorio-de-github).
