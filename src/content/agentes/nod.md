Nod es el agente personal de [n8n](/agentes/n8n). Tiene su propio «ordenador» y puede hacer recados en webs reales: por ejemplo, reclamar facturas, preparar una llamada o cancelar una prueba. Según el proyecto, pregunta antes de actuar. Se ejecuta en tu máquina con el modelo que tú elijas.

## Qué puedes hacer

- Encargarle gestiones en sitios web reales. El proyecto dice que pregunta antes de actuar.
- Usarlo en el escritorio. Hay app para macOS 14 o posterior, tanto Apple silicon como Intel, y una vista previa para Windows 11 y Linux x64.
- Elegir el modelo. El README indica que hace falta ChatGPT Plus o Pro, o una clave de API.

## Precio

El programa es gratis y de código abierto, con licencia Apache-2.0. El modelo se paga con tu suscripción o con tu clave. El código está en [n8n-io/nod](https://github.com/n8n-io/nod) y la web del proyecto es [nod.n8n.io](https://nod.n8n.io/).
