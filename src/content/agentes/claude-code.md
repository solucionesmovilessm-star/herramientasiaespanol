Claude Code es el agente de programación de Anthropic para la terminal. Lees el repositorio con él, le pides un cambio y revisas lo que escribe. Las skills de Claude Code viven en carpetas de tu equipo, no hace falta subirlas a la API.

## Qué puedes hacer

- Pedir un cambio en un proyecto que ya tienes en el disco.
- Guardar una skill en `~/.claude/skills/` o en `.claude/skills/` del proyecto. El tutorial está en [cómo añadir skills a Claude](/tutoriales/como-anadir-skills-a-claude).
- Instalar ejemplos oficiales desde el repositorio de Anthropic, con los comandos que publica ese README.

## Precio

Forma parte de la oferta de Claude. La documentación indica con qué plan o con qué uso de la API se abre. Esta ficha lo marca como de pago para no prometer un modo gratis que no hemos comprobado en la tarifa de hoy.

## Ten en cuenta

En la terminal el agente puede ejecutar comandos. Lee lo que va a lanzar. Las skills de documentos (PowerPoint, Excel, Word y PDF) que vienen en claude.ai no son las mismas que las de Claude Code.
