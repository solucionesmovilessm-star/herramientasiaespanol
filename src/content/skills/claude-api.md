La skill `claude-api` reúne material de referencia de la API de Claude y de los SDK: identificadores de modelo, parámetros, streaming, herramientas y temas vecinos. Anthropic dice que viene incluida con Claude Code y que también se puede instalar desde el repositorio de skills.

## Dónde está

Carpeta `skills/claude-api` en [anthropics/skills](https://github.com/anthropics/skills). Sirve cuando el agente tiene que escribir código contra la API y no debe fiarse de la memoria del modelo.

## Licencia

Lee la licencia de la carpeta. La referencia se queda obsoleta cuando Anthropic cambia un modelo: por eso la skill existe, para leerla en vez de recordar precios o nombres de memoria.

## Ten en cuenta

Aunque la skill hable de precios de la API, no copies esas cifras a una web. Cambian. Míralas en la documentación de Anthropic el día que las necesites.
