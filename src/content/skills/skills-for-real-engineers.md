Skills for Real Engineers es una colección de skills de Matt Pocock, conocido por sus cursos de TypeScript. Están pensadas para programar «de verdad, no vibe coding». Vibe coding es dejar que la IA escriba el código sin que tú revises el resultado con criterio.

Son skills pequeñas y se pueden combinar. La idea es que las adaptes a tu forma de trabajar. Sirven con cualquier modelo, no solo con uno.

## Qué puedes hacer

- Instalarlas en Claude Code con una línea. El repositorio indica este comando, y dice que se actualizan solas:

```text
claude plugin install mattpocock-skills@claude-plugins-official
```

- Seguir las instrucciones del repositorio para Codex y GitHub Copilot.
- Copiarlas a tu proyecto con [skills.sh](https://skills.sh), si prefieres tenerlas dentro de la carpeta.

## Precio

Es gratuito y de código abierto, con licencia MIT.
