La skill `pdf` enseña a Claude a trabajar con archivos PDF: extraer texto o tablas, unir o separar documentos, rellenar formularios, crear un PDF nuevo u ocr de un escaneo. Anthropic la incluye entre las skills de documentos que ya puede usar Claude al crear archivos.

## Dónde está

La carpeta está en el repositorio [anthropics/skills](https://github.com/anthropics/skills), dentro de `skills/pdf`. En claude.ai, las skills de documentos integradas se usan al crear archivos, sin que tengas que instalar esta carpeta. El código publicado sirve de referencia y, en Claude Code, se puede instalar el paquete de skills de documentos siguiendo el README del repositorio.

## Licencia

El archivo de la carpeta indica una licencia propia, no una licencia abierta. Lee `LICENSE.txt` antes de copiar el código a otro proyecto.

## Ten en cuenta

Anthropic avisa de que el repositorio es de demostración y de que el comportamiento dentro de Claude puede no coincidir con el de la carpeta. Prueba con un PDF que no sea confidencial.
