Frontend Design es un ejemplo del repositorio de Anthropic. La descripción oficial dice que orienta el diseño de una interfaz nueva o de una que se quiere rehacer: dirección estética, tipografía y decisiones que no parezcan una plantilla por defecto.

## Dónde está

Carpeta `skills/frontend-design` en [anthropics/skills](https://github.com/anthropics/skills). Sirve para ver cómo está escrita una skill de criterio, no solo de formato de archivo.
