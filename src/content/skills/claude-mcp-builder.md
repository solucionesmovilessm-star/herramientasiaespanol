MCP Builder es una skill para quien va a programar un servidor MCP. Recorre cómo diseñar herramientas que un modelo pueda usar, en Python con FastMCP o en Node con el SDK de MCP.

## Dónde está

Está en `skills/mcp-builder` del repositorio [anthropics/skills](https://github.com/anthropics/skills). No es un servidor MCP: es el manual que Claude sigue mientras escribe uno. Si lo que quieres es instalar un servidor que ya existe, ve al tutorial [cómo instalar un servidor MCP](/tutoriales/como-instalar-un-servidor-mcp).

## Ten en cuenta

Un servidor MCP que escribes tú tiene acceso a lo que tú le des. Empieza con una herramienta de solo lectura.
