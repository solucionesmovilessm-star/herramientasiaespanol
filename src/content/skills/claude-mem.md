claude-mem da memoria entre sesiones a Claude Code y a otros agentes de código, entre ellos Codex, Gemini, Copilot y OpenCode. Guarda lo que el agente hace, lo resume con IA y, en la sesión siguiente, le devuelve el contexto que le sirve. Así no tienes que explicarle el proyecto desde cero cada vez.

No es una skill oficial de Anthropic. Es un plugin de otro autor. Las skills oficiales están en [Skills para Claude](/skills/claude).

## Qué puedes hacer

- Conservar el hilo de un proyecto entre un día y otro.
- Usarlo con varios agentes de código, no solo con Claude.
- Leer las instrucciones en español: el repositorio tiene README en español.

## Precio

Es gratuito y de código abierto, con licencia Apache 2.0.
