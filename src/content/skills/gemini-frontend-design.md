Gemini Frontend Design es una skill del equipo de Gemini, en el repositorio DemoLab. Google la cita en el anuncio de [Gemini 4 Hydrogen](/noticias/gemini-4-hydrogen). Sirve para diseñar y construir webs y apps con mejor acabado: estructura, color, tipografía, imágenes, textos y movimiento.

Google dice que, en sus pruebas, los usuarios prefieren los diseños hechos con esta skill el 67 % de las veces frente a no usar ninguna, y el 75 % frente a skills de diseño de terceros muy usadas. Esas cifras son de Google, no una prueba de este sitio.

## Cómo instalarla

El comando que documentan es:

```bash
npx skills add google-gemini/demolab --skill gemini-frontend-design
```

También hay instrucciones para Antigravity (`agy plugin install`), Claude Code, Cursor y Codex. La skill está en [google-gemini/demolab](https://github.com/google-gemini/demolab/tree/main/skills/gemini-frontend-design) y el repositorio completo en [google-gemini/demolab](https://github.com/google-gemini/demolab).

## Precio

Es gratis y de código abierto, con licencia Apache-2.0. El modelo que use tu agente se paga aparte, si ese modelo es de pago.
