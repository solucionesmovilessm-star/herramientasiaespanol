Superpowers es un conjunto de skills combinables y una forma de trabajar para agentes de programación. La idea es que el agente no se ponga a escribir código a ciegas: primero te pregunta qué quieres hacer, redacta una especificación y te la enseña en partes cortas para que la revises.

## Qué puedes hacer

- Dar a tu agente de código un método ordenado: preguntar, planificar y después programar.
- Instalarlo en varios agentes. El repositorio tiene instrucciones para Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot CLI, OpenCode y otros.
- Combinar sus skills según el tipo de tarea.

## Precio

Es gratuito y de código abierto, con licencia MIT. El agente que uses puede tener su propio coste.
