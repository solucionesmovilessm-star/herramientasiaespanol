GitHub publica su propio servidor MCP. Conecta un asistente con repositorios, archivos, issues, pull requests y otras piezas de la plataforma, según las herramientas que ese servidor exponga en la versión que instales. Hay una variante remota alojada por GitHub y una variante local.

## Qué hace

- Leer código y el estado de un repositorio al que tu cuenta puede entrar.
- Abrir o actualizar issues y pull requests si la herramienta y el permiso lo permiten.
- Usar el token o el inicio de sesión que configures tú. El servidor no adivina una cuenta.

## Ten en cuenta

El permiso que concedas es el permiso que tendrá el asistente. Empieza con un repositorio de prueba y con el alcance más pequeño que te deje trabajar. El servidor antiguo que vivía dentro del repositorio de referencia de MCP está archivado: el que hay que usar es este, el de GitHub.
